# ✨ Tarot Birthday Reading

Tarot Birthday Reading is an interactive web experience built with React, JavaScript, HTML, and CSS. Designed as a digital birthday gift, it guides the user through a personalized tarot-inspired reading, where each revealed card uncovers a heartfelt message until reaching a final handwritten letter.

The project focuses on creating an immersive and emotional journey through cinematic animations, smooth transitions, magical visual effects, and responsive interactions. Rather than recreating a traditional tarot reading, it transforms storytelling into an elegant interactive experience.

Tarot Birthday Reading was created as a personal project to explore creative frontend development, advanced UI animations, and interactive storytelling using React and Framer Motion.

## ✨ Features

* 🃏 Interactive tarot card deck
* ✨ Smooth card flip and reveal animations
* 🎴 Shared layout transitions with Framer Motion
* 🌌 Animated particle background
* 💌 Magical envelope opening sequence
* 📜 Animated handwritten-style letter reveal
* 🌙 Glassmorphism modal with backdrop blur
* 📱 Fully responsive design

---

## 🧰 Tech Stack

* React
* Framer Motion
* CSS (custom animations)
* Vite

---

## ⚙️ Notes

* This project was bootstrapped with Vite.
* All animations and interactions were built from scratch without UI frameworks.
* The experience is optimized for both desktop and mobile devices.
